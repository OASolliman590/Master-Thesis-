# Pipeline Repo Source Of Truth

- Code: `src/`, `pipeline/`, `scripts/`, `tests/`, `configs/`, `inputs/`
- Authored docs: `docs/`
  - Canonical run guide: `docs/USAGE.md`
- Report artifacts: `reports/`
- Runtime outputs: `results/`, `logs/`, `work/`

Do not store runtime caches at parent workspace root.
