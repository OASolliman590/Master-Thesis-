# Methods basis for the planned source review

Verified 24 October 2026. This note concerns review methods only. No Prat paper, GEO record, source object or patient record was opened. It does not establish inventory contents, source completeness, biological facts or reader independence.

## Generic methodological guidance

- Link multiple reports to their underlying study; reconcile their information. [Cochrane Handbook, Chapter 5, §§5.2.1 and 5.5.4](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-05).
- Use piloted forms, version identifiers, coding instructions and source locations. [Chapter 5, §§5.4.1 and 5.4.3](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-05).
- Extract subjective and interpretation-critical information independently with at least two people; predefine disagreement handling. [Chapter 5, §5.5.2, including MECIR C45/C46](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-05).
- Compare independent passes, retain original extractions and consensus separately, and record unresolved disagreements. [Chapter 5, §5.5.5](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-05).

These recommendations concern systematic reviews; their Cochrane conduct labels do not themselves create DAV admission requirements.

## Adaptation to this planning packet

Use a fixed question set and common inventory version for separate first passes, followed by comparison and documented adjudication preserving both originals. Pilot question clarity using invented examples during planning; this does not establish successful piloting on real reports. Publication-family links remain questions until evidenced. These are DAV workflow adaptations of the sections above, rather than claims of completed review.

For optional provenance vocabulary, W3C PROV-DM describes derivation between entities and revision as derivation of a revised version. This can describe links among a source-object version, a reader artifact and a later adjudicated artifact; it does not select an authentication system or mandate adopting PROV. [W3C Recommendation, 30 April 2013, §§5.2.1–5.2.2](https://www.w3.org/TR/2013/REC-prov-dm-20130430/).

## Existing DAV authority and evidential limits

The [prior independent procedure review](../../validation/A_DAV_PRAT_PROCEDURE_01/INDEPENDENT_PROCEDURE_REVIEW.md), especially P01–P05 and P08, records the existing contract basis for exact object/version evidence, sealed first passes, authenticated review, preserved conflicts, selection-policy timing and the narrow private/export boundary. Those requirements derive from the cited frozen DAV documents and current brief, not from this methods search. This note neither changes their authority nor adds scientific defaults, thresholds, endpoint conversions or release criteria.

Peer-pass separation, report masking and outcome exposure are distinct. Cochrane does not generally recommend masking aspects of study reports; it does not establish blinding for this packet. [Chapter 5, §5.5.3](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-05). The DAV-specific safeguards still require an honest exposure record. No cited method proves that readers avoided shared answers or prior outcomes. A digest or named reviewer alone does not authenticate a review; actual appointments, custody, source access and authentication remain unresolved under [TASK.md](TASK.md).

Methods guidance supports designing the procedure. Only subsequently authorized evidence review can establish source facts; software or synthetic acceptance remains a separate checkpoint.
