# Amendment: V7 reviewer for public, non-controlled source objects

**Status:** APPROVED by the user in chat on 2026-10-25 ("q1 yes"). This applies on top of the frozen spec as a recorded project decision. The frozen spec files themselves are unchanged.

**Problem.** VALIDATION_FRAMEWORK V7 and RELATIONAL_INVARIANTS ("Receipts and cardinality") require a real, dated "source reviewer and integrator". The workstream could not find any appointed authority, so every public cohort stayed BLOCKED_UNKNOWN indefinitely, even though no institutional appointment is required for public GEO or author-release objects. ACCESS_PRIVACY_AND_REDISTRIBUTION requires institutional approval only for controlled access.

**Proposed text.** For source objects whose access route is public and non-controlled, the thesis author or the named supervisor may act as both source reviewer and integrator for V7. They sign the reviewer worksheet with their name and the date. A single signature satisfies the receipt cardinality rule for these sources. Controlled-access sources (dbGaP, EGA) keep the existing requirements unchanged.

**Effect.** Admission can be decided by one named human after one review of a generated worksheet. No reader appointments, custody authorities or two-reader rehearsals are needed for public objects.
