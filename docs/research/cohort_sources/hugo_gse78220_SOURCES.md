# GSE78220 sources and evidence

**GSE78220 has pretreatment melanoma biopsies and per-sample response labels, but it cannot yet enter `A_BASELINE_BIO` through the current field-map ingestion path.** Its selected expression object is an XLSX workbook, while the frozen field-map schema exposes only SOFT, delimited text, and matrix-header text formats ([field map schema](tools/a_dav/field_maps/field_map.schema.json)). A shared workbook adapter and confirmation of the workbook's expression header are needed before the branch can bind expression to specimens. The field map therefore declares only the supported GEO SOFT metadata object; it does not mislabel the workbook as text.

## Expected scope and source roles

GEO identifies GSE78220 as a human RNA-seq study of pretreatment melanoma biopsies collected to study anti-PD-1 response. The series lists **28 samples**. Every GEO sample record has a title in the `Pt...` form, a `patient id` characteristic, `biopsy time: pre-treatment`, melanoma tissue, a treatment value, and an `anti-pd-1 response` characteristic. Accordingly, the GEO metadata expectation is **28 total sample records and 28 baseline records**. The paper's transcriptome comparison reports 27 pretreatment tumours with available high-quality RNA plus one early on-treatment tumour, which conflicts with GEO's current per-sample pretreatment annotations; sample-level reconciliation remains open. [GEO series brief](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE78220&targ=self&form=text&view=brief) [GEO sample brief](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE78220&targ=gsm&form=text&view=brief) [Hugo et al., Cell 2016](https://pmc.ncbi.nlm.nih.gov/articles/PMC4808437/)

The patient identifier is in `!Sample_title` and `patient id`; the timepoint is in `biopsy time` (and GEO sample descriptions say “pre anti-PD-1 treatment”); response is in `anti-pd-1 response` and is also reflected in `!Sample_source_name_ch1` as a response suffix; tumour tissue is in `tissue` and source name. The response characteristic is the **source of record for this field map** because no author clinical response table was identified in the GEO record, linked publication, publication supplements surfaced from the article, or author-hosted code search. The paper's responder/non-responder group definitions corroborate the label construct but do not supply the primary per-patient table used here. Preserve GEO's raw response strings; do not silently collapse SD into objective response. [GEO sample brief](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE78220&targ=gsm&form=text&view=brief) [Hugo et al., Cell 2016](https://pmc.ncbi.nlm.nih.gov/articles/PMC4808437/)

The study treatment is anti-PD-1 therapy; GEO's per-sample `treatment` characteristic names pembrolizumab or nivolumab. The original paper says the cohort includes pretreatment pembrolizumab- and nivolumab-treated melanoma tumours. It describes prior MAPK inhibitor exposure for some patients, which is not prior immunotherapy. Prior ICI exposure is **UNKNOWN**: neither the inspected GEO fields nor the paper's patient-level discussion establishes a complete prior-immunotherapy field. GEO reports `previous mapki`, which must not be reinterpreted as prior ICI. [GEO sample brief](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE78220&targ=gsm&form=text&view=brief) [Hugo et al., Cell 2016](https://pmc.ncbi.nlm.nih.gov/articles/PMC4808437/)

The paper defines responding tumours as CR, PR, or stable disease control (excluding mixed responses) and non-responding tumours as progressive disease; these response patterns were based on irRECIST. This paper-level grouped definition is corroboration, while the individual raw label remains the GEO characteristic. The current map retains raw CR, PR, SD, and PD values and does not derive objective response from the paper's broader SD-inclusive “responding” group. [Hugo et al., Cell 2016, response definitions](https://pmc.ncbi.nlm.nih.gov/articles/PMC4808437/)

## cBioPortal cross-check

The public cBioPortal study search returns `mel_iatlas_hugo_ucla_2016`, described as a harmonized subset focused on whole-exome sequencing and 27 pretreatment tumours. It is not an expression or response source for this field map, and no cBioPortal patient table was retrieved. It provides a metadata-level confirmation that a 27-tumour pretreatment Hugo subset exists, but cannot resolve the GEO-versus-paper sample timing discrepancy. [cBioPortal Hugo study metadata](https://www.cbioportal.org/api/studies?keyword=hugo&projection=SUMMARY&pageSize=100)

## Author code search

No author-hosted GitHub repository with a patient-level response table or expression source was established, so no GitHub object is included in the fetch plan. A public third-party reanalysis repository was found, but it is not author source material and was excluded. Its API latest-commit result was `f35b0ed53d23ef9cf7c40de164679d246bc67bfd`; that pin is not used. ## Open questions

- Reconcile the 28 GEO samples all labeled pre-treatment against the paper's 27 pretreatment plus one early on-treatment transcriptome count. The expected acquisition inventory remains 28 GEO specimens / 28 GEO baseline labels until this discrepancy is reviewed.
- Add and validate a shared XLSX workbook adapter, then confirm the workbook's specimen headers against GEO sample accessions or titles without changing the source labels.
- Establish the exact expression unit and transform, gene annotation, feature identifier type, and whether workbook values are gene-level; current allowed source statements establish only Cuffnorm-normalized gene analysis and hg19.
- Establish patient-level prior immunotherapy history, exact regimen for every patient, response assessment details beyond the paper's stated irRECIST grouping, and whether duplicate patient-related labels such as `Pt27A`/`Pt27B` represent separate biological patients or related samples.
- The GEO processing notes say the tumour RNA was quantified and normalized by Cuffnorm for gene analysis; they do not specify Cuffnorm version or the precise exported quantity. Do not fill those details from the workbook filename alone.
