# Paper D: virtual-cell benchmark feasibility

Evidence checked 5 September 2026. Bounded, independent documentation audit; no model weights, training, inference, count matrices or experimental procedures. Files were written outside the canonical repository while its independent review was active.

**Recommendation, not a user decision: defer standalone execution until a compatible independent prostate benchmark is secured; preserve the complete conditional specification.** The public State ecosystem is real and includes chemical-perturbation checkpoints. However, an off-the-shelf State-versus-LINCS prostate benchmark would currently confound model generalization with input modality, gene space, drug vocabulary, dose and duration. The strongest new finding is that the inspected inference command can return control-like predictions for unknown perturbations rather than reject them. A successful command therefore cannot itself demonstrate support for an unseen drug.

## 2. Drug vocabulary and input contract: inspected evidence

Both downloaded Tahoe configs specify `pert_rep: onehot`, `pert_col: drugname_drugconc`, `cell_type_key: cell_name`, `batch_col: plate`, and random control/basal sampling. Dose is part of a categorical label, not a demonstrated continuous dose-response input. No duration covariate appears in those configs. The HVG configuration uses `X_hvg`; the SE configuration uses `X_state`. [HVG config](https://huggingface.co/arcinstitute/ST-HVG-Tahoe/resolve/ca6b751972493f8448e3256d1340ae70ad43e1e7/zeroshot/state_generalization_zeroshot_X_hvg/config.yaml), [SE config](https://huggingface.co/arcinstitute/ST-SE-Tahoe/resolve/03b1971d7cc93a7535fd2e957c6948dba267378b/zeroshot/state_generalization_zeroshot_X_state/config.yaml).

The saved HVG-zeroshot `pert_onehot_map.pt` and `var_dims.pkl` are small metadata assets, not checkpoint weights. They were downloaded and inspected with **`pickletools` opcode parsing; no unpickling or callable execution**. The dimension stream contains input/HVG/output dimensions 2000 and perturbation dimension 1138. The label payloads decode as UTF-32LE NumPy strings. Recovered **1138 unique labels**, corresponding to379 drug names at three doses plus one vehicle label. This is the exact inspected checkpoint vocabulary, not a universal State capability. [Original vocabulary](https://huggingface.co/arcinstitute/ST-HVG-Tahoe/resolve/ca6b751972493f8448e3256d1340ae70ad43e1e7/zeroshot/state_generalization_zeroshot_X_hvg/pert_onehot_map.pt), [dimensions metadata](https://huggingface.co/arcinstitute/ST-HVG-Tahoe/resolve/ca6b751972493f8448e3256d1340ae70ad43e1e7/zeroshot/state_generalization_zeroshot_X_hvg/var_dims.pkl).

The literal entries include `[("Decitabine",0.05,"uM")]`, `[("Decitabine",0.5,"uM")]` and `[("Decitabine",5.0,"uM")]` (actual serialized spelling uses single quotes and spaces). Searches over decoded labels found no entinostat, MS-275/MS275, tazemetostat, E-7438 or EPZ-6438 labels. This establishes absence under the inspected names; a complete structure-level alias audit is still required before declaring compounds globally absent. The control key is `[("DMSO_TF",0.0,"uM")]`; note that the saved config's control string is only `DMSO_TF`. A wrapper must inspect actual vocabulary/AnnData labels instead of blindly adopting either spelling.

At the pinned source commit, `tx infer` requires a trained run with config, dimensions and saved one-hot mapping. For a perturbation label absent from the mapping, lines 756–806 construct/use a default control one-hot; a message is conditional on verbosity. For a cell group with no matched controls, lines 747–754 permit global-control fallback; if none exist anywhere, lines 775–780 can leave rows unchanged. **Proposed adapter invariant:** reject unknown treatment labels, mismatched dose units, absent group/batch-matched controls and feature-order mismatches before calling upstream inference. Never interpret fallback output as a negative drug effect. [Pinned inference source](https://github.com/ArcInstitute/state/blob/9bbfe78a434a55205e4de834e1ea99f85f7a3add/src/state/_cli/_tx/_infer.py).

## 5. Proposed primary estimand and validation design

**Proposal, conditional on a compatible dataset:** mean paired reduction in fixed-gene-space, condition-level squared error of the observed expression-change vector, comparing the frozen State checkpoint with one baseline selected on development data. For condition c, `gain_c = MSE(delta_observed_c, delta_baseline_c) - MSE(delta_observed_c, delta_State_c)`; primary estimate is an equally weighted average over prespecified eligible conditions, with drug-level weighting/cluster handling to prevent one heavily sampled drug dominating. Positive values favour State. Feature space and training-only scaling are frozen before test access. An immune-program subset is secondary, not an outcome-selected way to rescue global failure.

Independent observational unit: independently assigned **drug–dose–cell-context experimental replicate/well**, retaining experiment and plate provenance. Cells are nested measurements; one culture's 10,000 cells are not10,000 independent perturbations. Evaluation conditions cluster within drug/experiment. If biological replication is unavailable, report descriptive condition accuracy and sensitivity, without cell-bootstrap population-level confidence claims. Splits must keep all cells/replicates of a held-out condition together; assay batches should also be separated where feasible. A new single-cell test dataset acquired after checkpoint training can still share biology or training-study sources; audit both.

Baselines to preregister: (1) no change/matched control; (2) training-only mean perturbation effect; (3) same drug's mean effect in other training contexts where the task permits it; (4) a ridge or nearest-neighbour model using the same allowed features/context information. Select the primary comparator using development data, then freeze it. No baseline can use held-out response values. An observed replicate-versus-replicate analysis is an empirical reproducibility reference, not automatically a theoretical ceiling.

Secondary evaluations: measured immune-program change error; direction accuracy excluding near-zero effects by a rule fixed without test tuning; perturbation discrimination/rank recovery; performance stratified by observed effect size and context. Cell-Eval provides predicted/real AnnData evaluation and per-perturbation results; using it does not validate biological independence or make expression-space mismatch disappear. Its documented cell-split ceiling is a within-dataset cell-sampling calculation, not evidence of between-culture reproducibility. [Cell-Eval](https://github.com/ArcInstitute/cell-eval).

## 6. Proceed/narrow/defer gates

| Gate | Evidence needed | Current verdict |
|---|---|---|
| Runtime contract | Exact checkpoint/config/code compatibility and a small inference run with known vocabulary and correct feature order | Assets found; no inference run; **open** |
| Input validity | Baseline single-cell data in a supported representation; matched context/batch controls; no unknown-label/control fallback | No qualifying prostate inputs established; **open** |
| Perturbation validity | Structural drug identity, supported exact dose label, compatible duration and assay | Decitabine labels exist; other planned drugs unconfirmed; inspected LINCS doses mismatch; **not satisfied** |
| Independence | Checkpoint-specific ST training split and SE pretraining provenance; sealed external test with declared overlap | Released nonprostate splits found; external prostate independence unproven; **not satisfied** |
| Measured endpoint | Real response data, adequate feature overlap/replication and frozen fair baselines | None established for native prostate test; **not satisfied** |
| Novel contribution | Result answering a distinct prostate prediction/utility question beyond existing benchmarks | Candidate question only; **open** |

**Proceed only with a limited implementation reproduction** on the released nonprostate Tahoe split if useful to validate the adapter within the existing 15-hour feasibility cap. Label this a software/methods checkpoint, not completion of Paper D. **Narrow to an appendix in C** only if an independently justified external-transfer comparison can be made without weakening the main pharmacology evidence. **Defer the standalone paper** if the required prostate inputs/ground truth, overlap ledger or runtime are unavailable within the cap. Do not rescue feasibility by training a new large model, silently changing D to a general pan-cancer benchmark, or calling a control fallback an unseen-drug prediction.

Conditional four-figure outline: (1) exact checkpoint/data/feature/overlap coverage; (2) State versus frozen baselines on independent conditions; (3) immune-program and perturbation-discrimination utility; (4) failure conditions by context, exposure and signal strength. All four require measured evidence. No claim of clinical ICI response, TME conversion or treatment benefit follows from this benchmark.

## Audit artifacts and remaining questions

Adjacent `D_virtual_benchmark/` contains official repository/model API responses, pinned configurations, split files, small original cell/drug metadata, vocabulary/dimensions metadata, decoded label strings and URL/size/SHA256 access manifests. No checkpoint or expression matrix was downloaded. The original small Parquet cell/drug files were cached but not locally parsed because no Parquet engine was available; viewer evidence is explicitly partial. No scientific prediction or executable benchmark passed in this audit.

Open factual questions: Which actual prostate single-cell drug dataset has compatible treatment/time/replication? Which precise output genes are common and independently measured? Can a particular pretrained checkpoint represent the shortlisted compounds after structural matching? Are controls and all training sources auditable? Does the exact pinned runtime run on AIU within budget? Design choices pending these facts: native single-cell primary task, admissible external transfer, fixed feature weighting, primary baseline, precision target and manuscript boundary. Unknowns stay unknown rather than becoming confident answers during grilling.
