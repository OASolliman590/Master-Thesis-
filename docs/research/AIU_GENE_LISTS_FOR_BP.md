# AIU historical gene lists relevant to Paper B-P

Date: 6 September 2026. Status: bounded read-only source-reuse audit after the user selected B-P external prediction improvement. No historical pipeline stage was rerun, no model was fitted, and no AIU job was started.

## Bottom line

No recovered historical gene list is defensible as an unchanged replacement for B-P's still-unapproved eight-gene antigen-presentation candidate `P={HLA-A,HLA-B,HLA-C,B2M,TAP1,TAP2,PSMB8,PSMB9}`. Reuse the old pipeline's provenance schemas, raw/canonical identifier fields, signed-effect fields, content hashes and explicit internal-versus-external validation gates. Do not reuse a historical biological membership as the primary endpoint without a new outcome-independent freeze.

The closest old mechanism panel is `PRC2_IMMUNE_TARGETS`: it contains 6/8 proposed P genes, but it is an unweighted, unoriented curated pathway panel rather than an externally validated predictor. It can inform the biological crosswalk; it does not justify adding or removing genes from P. A list selected or changed after inspecting CPC-GENE outcomes cannot then be evaluated on the same CPC patients as independent external validation.

This audit follows the selected [B-P decision](../decisions/B_PRIMARY_BP_20260906.md) and the current [analysis contract](../../specs/B/ANALYSIS.md). P itself, the common expression universe U, promoter lists Q, specimen policy, covariates and precision thresholds remain unresolved measurement/design choices.

## Error boundaries

The GSE115821 defect is directly demonstrated for the July 11 run and for the committed Spec 008 allocation pattern. It must not be silently projected onto every earlier list. The April/May/June exact sample manifests were not recovered in this bounded pass, so whether they share the same defect remains unknown.

The July core is not rescued by renaming `6-Sep`. GSE115821 locus evidence supports SEPTIN6 as a candidate mapping, while the GSE126044 row remains less directly supported; date-like collisions occur in both source files. Canonicalization requires a versioned ambiguity-aware mapping and recomputation from corrected inputs. It cannot be achieved by changing a printed label.

Neither internal LOCO nor TCGA prognostic projection is independent external ICI-response validation. The June and July validation summaries explicitly report missing held-out evaluation. None of the inspected artifacts proves that CPC-GENE outcomes were never accessed; this remains unknown rather than “clean.”

## Best-supported reuse recommendation

1. Keep B-P's current candidate P separate from all historical responder lists. Freeze or amend P using literature, annotation, cross-platform measurement and TCGA-only design evidence before any CPC outcome inspection.
2. Reuse engineering concepts only: content-addressed list files, raw plus canonical identifiers, ambiguity flags, signed direction/effect fields, contributing-cohort counts, run/config hashes, and explicit `internal_nested_loco` versus `external_holdout` status.
3. Use `PRC2_IMMUNE_TARGETS` only to document that six proposed P genes already appeared together in an older mechanistic panel. It is not evidence for PSMB8/PSMB9, equal positive orientation, the B-P rank endpoint or predictive improvement.
4. If an old learned list is ever reconsidered, register it as a separate exploratory endpoint with its historical TCGA exposure and missing CPC-exposure provenance. Do not use CPC outcomes to select among June, July, GMT or P variants and then call the winning CPC result external validation.
