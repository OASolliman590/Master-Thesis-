# Scope change and migration

User request of 15 October 2026 controls this revision. It supersedes the 13 October experiment-dependent Paper E implementation order, not the university protocol or the biological paper.

| Old v1 dependency | v2 disposition |
|---|---|
| Local surface-HLA prospective trajectory is proposed primary | Moved to E_LAST; core primary is a prespecified model-level schedule-contrast identified set |
| E3 requires local experiment admission | E3 uses admitted public PD or explicit partial-identification constraints |
| E4 requires local checkpoint assay before any QSP analysis | E4 uses qualified external evidence for calibration; unsupported interactions are labelled hypotheses and stress-tested, not claimed validated |
| E5 prospective internal validation precedes E6 populations | Core E5 is independent public evaluation plus identifiability; experimental prediction workflow is X4, implemented last |
| Lab inventory/reagent/ethics blocks core production | These block only relevant E_LAST modules; public-data terms remain mandatory |
| All virtual members could be called patients | Calibrated population, plausible parameter ensemble and bounded uncertainty set are distinct types |
| One generic completion status | Separate spec/software/data/scientific-core/empirical/prospective states |

The original ZIP remains unchanged outside this bundle. Active specifications were revised, not merely overlaid with an optional-data disclaimer. Compatibility schemas are retained at version 1.0.0 where fields did not change. New profile/activation contracts are version 2.0.0. Synthetic examples are test fixtures, never experimental records.
