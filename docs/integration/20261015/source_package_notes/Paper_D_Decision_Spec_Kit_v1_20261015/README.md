# Paper D Decision and Specification Kit — v1.0

This package converts the approved Paper D amendment into a standalone, reviewable specification and implementation handoff for:

> **A data-grounded hybrid virtual tumour–immune model for testing epigenetic priming and checkpoint-blockade hypotheses in prostate cancer.**

It preserves the original conditional virtual-cell benchmark rather than replacing it. It also prevents that unresolved benchmark from blocking a separately validated measured-driver tumour–T-cell model.

## What is included

- approved D-A–D-H decision record;
- exact historical D1 primary estimand and fixed comparator;
- source-acquisition and validation gates G0–G10;
- model, checkpoint, perturbation, ontology, and overlap contracts;
- D2-PAIR and conditional D2-TISSUE/learned-coupling architecture;
- PhysiCell/PhysiBoSS boundary contract;
- Paper D ↔ Paper E interface and shared-experiment ledger;
- validation ladder V0–V8, baselines, uncertainty, and identifiability;
- in-silico hypothesis registry and prospective wet-lab handoff;
- four gene/readout panel contracts without falsely freezing a final discovery list;
- machine-readable JSON Schemas and valid synthetic examples;
- 19 bounded D-Rxx work packets;
- a local package validator and validation receipt.

## What is not included

- a trained or fine-tuned model;
- a qualifying independent D1 prostate test matrix;
- a completed Lin et al. reproduction;
- a calibrated PhysiCell tumour–immune system;
- a wet-lab result;
- a GitHub branch, commit, pull request, or merge;
- authorization for controlled access, paid transfer, author contact, clinical recommendations, or large training.

## Repository destination

After review, integrate the dated specification under:

`specs/D/revision_20261015/`

Preserve all historical `specs/D/` files and the original Paper D issue. The approved integrator owns commits, pushes, and the draft PR; this package must not be merged automatically.
