# Cross-paper interface contract v1.0-review

Every handoff must carry artifact_id, artifact_version, authoritative_owner, schema_version, source_object IDs, source/input/output SHA-256, release IDs, data-role lineage, originating study/publication family, permitted/blocked uses, provenance locators and review receipt. A missing field blocks that handoff, not unrelated modules. Numerical units and transformations must be explicit; unknown is never zero. A changed source, schema, role, feature ordering or fitted parameter invalidates dependent hashes and requires a new version, migration test and re-review.

| Artifact/owner | Semantics and identifiers | Units/sign/weights | Admission and allowed use | Invalidation |
|---|---|---|---|---|
| DAV.identity.v1.1 / DAV | study, family, private patient, treatment_episode, specimen, assay, outcome; explicit bridge | source units preserved; no outcome reuse across episodes | reviewed identity, exact objects, role/exposure and branch receipts; private rows never published | identity/episode/role correction invalidates affected matrices |
| A.bio.v1 / A-BIO | gene/programme associations with context, uncertainty and contradiction | effect scale and association direction distinct from penalized coefficient | development-only frozen biological evidence to B/C; not causal or predictive-superiority claim | new selection, normalization or development exposure invalidates handoff |
| A.score.v1 / A-PRED | ordered features, coefficients, transforms, frozen model | declared measurement scale and coefficients; fixed CYT comparator separate | final test cannot tune selection; no gene truncation while claiming original score | model/feature/transform change needs new independent evaluation |
| B.query.v1 / B | separate matched Q_M/Q_E programmes, gene/direction quotas and regulatory provenance | quota parity; optional supported weights; regulatory association is not reversibility | TCGA discovery-only query freeze before C effects; CPC outcomes excluded | membership, quota, evidence or role change invalidates C query |
| C.evidence.v1 / C | compound canonical ID, perturbagen aliases, context, dose/time, measured experiment | full-universe directional rank score; source-equal paired Delta_Q | measured independent evidence, coverage and budgets frozen; connectivity is not efficacy or kinetic rate | context/source/query/scorer change invalidates ranking and downstream use |
| D.prediction.v1 / D | model/checkpoint, ordered measured genes, biological units, context | exact theta comparator/weights; prediction uncertainty explicit | benchmark-gated molecular prediction; not E measured calibration; unsupported B/TLS output typed UNSUPPORTED | checkpoint/gene order/comparator/bridge change invalidates predictions |
| E.exposure.v1 / E | compound/formulation, compartment, schedule, population/scenario | concentration units, free/total basis, time origin/time unit, uncertainty | qualified public PK/PD numerical evidence; bounded exposure/scenario support | unit/time/binding/source/model change invalidates D/E consumers |
| E_LAST.observation.v1 / E_LAST | experiment, donor/block, assay, source and approvals | measured quantity/unit, calibration vs independent validation role | accepted E foundation plus admitted original observations; optional | reuse for calibration removes independence for same model version |

Adapters reuse identity/hash/role primitives with namespaced clinical, cell-experiment, LINCS-signature and PK-aggregate records. They do not coerce all entities into patient rows. Adapter migration tests must preserve keys, units, nulls, role exclusions and complete provenance; unknown mappings fail closed. No production adapter is claimed implemented by this document.
