# Shared lineage and experimental-use governance

Use `lineage_ledger.template.tsv` as the common envelope, with private namespaced extensions owned by DAV, B, C, D and E. This header-only template contains no admitted rows. It does not replace DAV patient/episode schemas. Record source object and publication-family identity, model/version, calibration/development/evaluation role, exposure state, permissions and invalidated dependants before fitting.

A final-test families, including related specimens, remain protected across A-BIO, A-PRED, A.1 and downstream query selection. B CPC outcomes cannot select TCGA discovery queries. C independent experiments cannot be used to tune the queries they evaluate. E public evaluation cannot be repurposed for calibration and remain independent for the same version. New wet-lab measurements cannot calibrate and independently validate the same model. Reuse in a later model version requires explicit role change and a fresh independent evaluation set.

Never inspect held-out outcomes to settle a specification disagreement. Unknown exposure blocks untouched-test claims. Private IDs, raw logs, signed protocols and patient/assay matrices remain outside Git; only approved aggregate/hash receipts enter the public repository. Source access and scientific release are separate. Current live AIU jobs and remote private data state remain UNKNOWN.
