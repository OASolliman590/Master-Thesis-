# Provenance uncertainty in A/A.1 source review

**Question.** Under the frozen shared DAV contracts, must a current official source object be proved byte-identical to its 2017 counterpart before any substantive review, or can the current object be pinned while historical continuity remains uncertain?

**Finding.** No shared-DAV rule makes historical byte identity with a 2017 object a universal prerequisite to substantive review. The contracts require a specifically identified, versioned object and full-byte hash for the bytes actually retrieved, sufficient publication-family/source-set coverage for the claimed review, object-level terms and custody, and source-backed evidence for each downstream claim. A current representation can therefore be reviewed as that pinned representation while prehistory remains explicitly unresolved, provided the responsible custodian/reviewer determines the scoped object set is complete for the intended claims and the unresolved history does not make a dependent claim unreviewable. This is a contract interpretation, not a finding that the history is immaterial or that the source is accepted.

The processed-data policy prioritizes an original-author processed object tied to the publication, then an official repository object with version/history; it allows multiple audit representations but requires one named branch representation to be frozen before analysis. ## Decision boundary for wayfinding

- **Unknown prehistory:** The pinned current record is identified and internally hash-verified, while the available evidence does not resolve its continuity/correction history. Record the uncertainty and let the source-specific review decide which claims it affects. Do not call this an observed difference.
- **Unexplained difference:** Two or more identified objects/versions or a repository replacement establish an actual version/content discrepancy whose source relationship or impact is unresolved. Per the Prat checklist, the affected dependent review cannot pass until the discrepancy is explained. If an object is determined not to be required for a particular claim, document that scope decision and the remaining limitation; do not describe a required-but-missing object as scoped away.
- **Missing required object:** If a custodian’s justified inventory says an original/correction/reanalysis object is required for the target claim, failure to locate or inspect it blocks that claim. If it is not required, document the bounded search and limitation; do not assert global absence.
- **Permission/custody:** Unknown terms, approved custody, or authorized readers are separate blockers. A historical provenance conclusion cannot supply them.

Thus, reviewing the current official item is **feasible under the contracts in principle**, with the unknown history retained and any affected claim left `BLOCKED_UNKNOWN`. It is **not currently clear or authorized operationally**: the earlier custody-readiness snapshot reports custody authority and custodian appointment not established, readers unassigned, inventory not reverified, and private review not run. Its earlier unknown public-access route is superseded by the later authorized public retrieval; that earlier field is not a current access blocker. Preliminary public inspection was authorized, while operational custody and authenticated source review remain unestablished. ([`STATUS.json`, lines 4–21](../../../docs/evidence/A_DAV_PRAT_CUSTODY_READINESS_01/STATUS.json#L4-L21); [`SOURCE_OBJECT_CHECKLIST.md`, lines 31–33](../../../docs/evidence/A_DAV_PRAT_SOURCE_REVIEW_PLAN_01/SOURCE_OBJECT_CHECKLIST.md#L31-L33).) The source-plan status also says source review is not run and source readiness remains `BLOCKED_UNKNOWN`. ([`STATUS.json`, lines 2–35](../../../docs/evidence/A_DAV_PRAT_SOURCE_REVIEW_PLAN_01/STATUS.json#L2-L35).)

The factual question for the human/source reviewers is: **Does the approved, scoped evidence set require the 2017 supplement (or another historical/corrected object) to support any target claim, or may the current Figshare v1 object be the pinned representation with historical continuity recorded as unresolved? For each claim, identify the evidence dependency that would change its disposition.** This asks for a source-scope and dependency decision; it does not grant authorization, appoint readers, or admit Prat.
