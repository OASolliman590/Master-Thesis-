# A/A.1 first-source shortlist

**Recommendation under the criterion “fewest still-unverified mandatory gates”:** take **Riaz / GSE91061 × `A_BASELINE_BIO`** through the first bounded source-to-review handoff, with `A1_ON_R_NR` queued for later. Confidence is **moderate** for this ordering, not eligibility or admission. The baseline branch requires source-supported pre-index tumour expression, an evaluable exact ORR or named source-binary endpoint, and shared V1–V6 gates. The retained audit provides baseline patient/visit/response metadata and a GEO header identity check, while whole-object measurement suitability and source/QC exclusions remain unresolved. This makes baseline review the smaller first unit. `A1_ON_R_NR` shares those baseline requirements and adds a verified pair/window, same-episode binding, endpoint evaluability on that pair, and no disqualifying treatment change; the historical audit did not validate those pairs. A.1 remains a reasonable next branch, but is a larger first review unit ([branch criteria](../../../specs/A_DATA_ACQUISITION_VALIDATION/COHORT_ADMISSION_AND_RELEASE.md#L9-L20); [A.1 longitudinal inputs and pairing requirements](../../../specs/A1/LONGITUDINAL_DATA_CONTRACT.md#L1-L10)). This recommends route order; the user's choice remains open.

## Evidence behind the recommendation

**Current public record check (24 October 2026):** NCBI GEO currently identifies GSE91061 as 109 RNA-seq profiles from 65 patients, with 51 pretreatment and 58 on-treatment samples, and links it to SRP094781 and PMID 29033130 ([GSE91061](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE91061)). The original Riaz paper describes the CA209-038 nivolumab study, its baseline and cycle-1 on-treatment biopsy design, and a public author repository containing additional processed data and code ([Riaz et al., *Cell*, 2017](https://pmc.ncbi.nlm.nih.gov/articles/PMC5685550/); [author repository](https://github.com/riazn/bms038_analysis)). The current GEO page corroborates the high-level series shape; it does not establish current bytes, eligibility, or a specific pair.

**Retained historical audit (6 September 2026, not repeated here):** the audit pins the author repository revision and reports a source-level patient/visit/BOR/prior-ipilimumab metadata trail; it reconciled all 51 baseline records to that metadata, while retaining the unresolved paper/code exclusion discrepancy. It also inspected only a 64 KB compressed prefix of the GEO FPKM object: its complete header matched all 109 GEO sample titles, and its source metadata described Entrez IDs, hg19 knownGene, and an FPKM representation. The prefix did not validate the whole matrix, all-feature coverage, QC, or a complete scale conversion. These are historical audit findings, not new measurements ([retained audit, provenance and clinical episode details](../../../docs/research/A_source_admission_91061/REPORT.md#L7-L35); [processed object limits](../../../docs/research/A_source_admission_91061/REPORT.md#L45-L55)).

## Why this source leads the bounded comparison

- **Riaz / GSE91061:** strongest first route for `A_BASELINE_BIO` by this gate-count criterion: current GEO and the primary paper identify the pre-index nivolumab context; the pinned author materials and retained audit provide baseline patient/visit/BOR metadata; the processed-object header was historically matched to GEO titles. Remaining baseline gates include current object/version reconciliation, full-object assay suitability/annotation, the source/QC discrepancy, and applicable shared custody, exposure, and review gates. `A1_ON_R_NR` remains plausible but adds pair/window, same-episode endpoint, and treatment-continuity evidence that has not been assembled. Prior ipilimumab must stay an exposure stratum within this study, not be split into an independent cohort. The audit flags unresolved biological patient overlap with Hugo and signature-specific prior use ([audit limits and exposure notes](../../../docs/research/A_source_admission_91061/REPORT.md#L37-L43), [overlap and exposure](../../../docs/research/A_source_admission_91061/REPORT.md#L57-L81)).
- **Hugo / GSE78220:** a useful queued baseline candidate, but a weaker first A.1 route. Current GEO describes pretreatment melanoma and 28 profiles; the retained audit identifies one on-treatment profile and two pretreatment sites from one patient, yielding 26 distinct baseline patients. The original paper's broader response grouping uses irRECIST and includes stable disease control, while the deposited GEO labels do not resolve that crosswalk; the linked FPKM workbook was not header-certified in the audit ([GSE78220](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE78220); [retained audit](../../../docs/research/A_source_admission_91061/REPORT.md#L55-L70)).
- **Prat / GSE93157:** a credible queued A baseline route with publication-level response and assay descriptions, processed sample-table data advertised by GEO, and a retrieved official supplement. Its retained public-record reviews still identify unresolved individual specimen/outcome binding, exact selected-object measurement provenance, and pending independent re-verification of the exact response-method passage ([public source inspection](../../../docs/research/A_DAV_PRAT_PUBLIC_SOURCE_INSPECTION_01.md#L7-L16); [public-record gaps](../../../docs/research/A_DAV_PRAT_PUBLIC_GAPS_02.md#L17-L34)). The platform and method descriptions help frame a review, but do not currently connect an individual episode to a selected measured object as directly as the Riaz audit trail does.

This ranks **review-route readiness only**. It does not admit Riaz, appoint readers, assign a final-test role, or establish eligibility for `A_BASELINE_BIO`, `A1_ON_R_NR`, or any other branch. The map explicitly separates retrieval, interpretation, review, and admission, and leaves source decisions with the parent/human decision ticket ([A/A.1 map](MAP.md#L3-L13)).

## Bounded next inspection unit and stop conditions

If the user selects this route, the first unit is one **baseline-object and endpoint review** for `GSE91061 × A_BASELINE_BIO`: record the current official GEO file locator/version metadata; reconcile the historical complete-header match with GEO's current title list, without inspecting expression rows; and review the already retained baseline source crosswalk and original endpoint definitions for provenance gaps. Do not expand into on-treatment pairing, inspect molecular values, or execute analysis. This defines the first review boundary; it does not itself pass V1–V6 or admit the branch.

Stop the baseline object review if the current official locator is absent/changed and cannot be pinned, if header reconciliation requires inspecting expression values, if sample columns fail to reconcile to GEO's current titles, or if exact ORR/source-binary provenance or pre-index status cannot be supported. Keep A.1 queued if source documentation cannot bind baseline and on-treatment records to the same patient and nivolumab episode, establish the declared window and endpoint, or rule out a disqualifying treatment change. Either outcome leaves the relevant route unresolved; it does not establish a software defect or change the branch contract. Terms, custody, actual reader authentication, and project authority remain prerequisites to individual review, as recorded in the retained audit and Prat gap review.
