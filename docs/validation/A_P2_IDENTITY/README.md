# A-P2 identity and overlap registry

This patient-free registry records source evidence and the signed overlap dispositions. It is not a roster, a signed run release or proof of disjoint patients. Study-namespaced tokens demonstrate token uniqueness only. See the signed 15 November amendment for the authoritative evidence criteria, grouping, A1 rule and residual risks.

The 21 development pairs follow section 3 of that amendment: Liu–Van Allen grouped, five US-linked pairs in conservative sensitivity, and Tier 3 only where its criteria apply. Each selected development cohort also requires a final-test pair. The six melanoma or gastric pairs against IMvigor210 are Tier 3 (different cancer types), confirmed by the user on 19 Nov 2026; the GSE176307 pair is RESOLVED_BY_SOURCE_RULE: the A1 exclusion was executed and hash-verified on 19 Nov 2026 (33 of 87 excluded from the freeze fit; GEO io.therapy only, no outcomes opened). No final-test data may be opened to resolve any pair. GSE111636 is outside selected inputs and its unresolved pair does not block.

Grouping does not remove duplicate contributions from other training folds, the equal-study average or secondary splits. Source treatment metadata may fail to capture prior therapy. Both prespecified main and conservative results must ultimately be reported regardless of direction. Prior exposure remains a gate before final-test release or comparator/novelty claims. The seven-cohort adaptive analysis does not include Braun; its separate implementation and release remain pending.
