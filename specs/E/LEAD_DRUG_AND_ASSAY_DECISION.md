# Public-core compound, antibody and measurement selection

This is an evidence-coverage decision, not a favourable-result contest. Laboratory stock, commercial tablets, donor availability and local instrumentation do not select the core lead. Select one agent and one checkpoint axis for the primary analysis, with context-specific evidence and no assumed interchangeability.

Public-source coverage is coded verified-object / inspectable-figure / metadata / unresolved, not invented numerical scores. Record source families and outcome exposure at the decision date. Exclude sources only by predeclared relevance/access/quality rules, not sign.

## Checkpoint

PD-1/PD-L1 is the initial axis to audit; the selected antibody still requires a public PK source and a functionally relevant evidence contract. Target binding, receptor occupancy and functional blockade remain separate. CTLA-4/LAG-3 substitution requires a new model contract and decision, not a renamed parameter file.

## Selection gates

Require resolved parent/salt/formulation/route, numerical PK, a public biological constraint in the chosen context, feasible open implementation and a source-level evaluation plan. Choose C-SCHEDULING only when its extra temporal/function gates pass; otherwise assess C-IDENTIFIABILITY. A public core lead may differ from the later experimental drug. E_LAST then opens a new compound/context branch rather than relabelling the completed model.

The primary assay in core is whatever admitted external source actually measured. The old proposed local surface-HLA assay is not a mandatory measurement here.
