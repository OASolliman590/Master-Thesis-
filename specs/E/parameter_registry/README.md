# Parameter coverage and evidence

PARAMETERS and PARAMETER_COVERAGE_V2 list unresolved **candidate** parameter roles, not one oversized fitting vector. Select a minimal identifiable subset per structure. Unlisted parameters in a selected public upstream model also require evidence rows before use. No candidate value or population distribution is released here. Every final value needs source locator, raw/canonical units, statistic/N, extraction, uncertainty/assumption class, reviewer, version and permitted role.

Numeric values in inherited public JSON examples are bounded historical curation fixtures, not defaults. An unmeasured rate may remain a profiled/set-valued unknown; do not create finite biological bounds solely for numerical convenience.
