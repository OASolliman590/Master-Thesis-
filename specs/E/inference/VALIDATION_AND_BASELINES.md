# Validation and baselines without original experiments

| Check | What it establishes | What it does not |
|---|---|---|
| Schema/unit/source verification | Inputs mean what the program expects | Biological truth |
| Source numerical parity | A recovered/reimplemented model matches published computation in stated tests | Independent empirical prediction |
| Independent systemic PK | Prediction of actual unused matched exposure observations | Prostate delivery or immune efficacy |
| Independent public PD | Prediction of actual unused assay/time/exposure observations | Every downstream biological link |
| Independent public functional comparison | Prediction of a qualified measured endpoint in its own context | Human clinical response |
| Held-out parameter/structure tests | Optimisation/generalisation within model assumptions | New biological validation |
| Actual prospective original challenge | Only E_LAST, after a frozen receipt and independent generated data | Automatic whole-framework validation |

## Required baseline family

For systemic exposure compare the recovered physiological structure to a parsimonious compartmental alternative. For PD compare no-effect/no-delay or exposure-only to the selected delayed/turnover model. For QSP compare no-priming interaction and direct-toxicity-only explanations where compatible with observations. For schedule selection compare fixed policies before optimisation. Train/tune on identical permitted development data and predeclare complexity selection.

Use source-appropriate prediction errors, bias and uncertainty coverage; retain residual plots and fit instability. No universal two-fold, p-value or solver-success threshold closes every validation level. Independent source holdouts must not have been used by an upstream pretrained/recovered model unless classified as reuse/reproduction rather than unseen validation. Unknown upstream overlap is not independence.

## Public evaluation freeze

Write a timestamped receipt containing source family IDs, frozen model/data/code versions, predicted observations, assay-scale metrics, missing/BLQ handling and permitted baseline covariates before the held-out numerical outcomes are exposed to the fitting process. If the analyst already viewed outcomes, document this; use model-development cross-validation or an additional independent source rather than claiming a prospective blind test.

No suitable functional or schedule holdout may exist. In that case list those levels as **not independently evaluated**, restrict the claim and complete the approved conditional/identifiability profile. Core still requires its prespecified independently evaluated exposure component and substantive biological constraints. This is not permission to relabel every unavailable evaluation as passed.
