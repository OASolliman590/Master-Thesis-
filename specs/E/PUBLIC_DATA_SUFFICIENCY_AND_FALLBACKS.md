# Public evidence availability: predetermined responses

| Available public evidence | Permitted analysis | Forbidden inference / required response |
|---|---|---|
| Human concentration profiles with known events and independent studies | PK fitting/evaluation in the source populations | Not a prostate tissue-delivery validation |
| Public PK but a published PBPK model has unpublished inputs | Independently reimplement recoverable processes; compare with simpler PK | Do not claim exact reproduction or require confidential inputs |
| Drug-specific proximal PD time series | Engagement/delay/turnover comparison on its assay scale | Do not rename PBMC HDAC kinetics tumour HLA recovery |
| Tumour molecular/protein endpoints at one time | Static response constraints and partial-identification analysis | Do not fit all induction/recovery rates |
| Public time course during dosing but no recovery samples | Estimate supported induction combinations; profile unresolved recovery | Do not infer heritable memory or a precise post-washout window |
| Tumour-specific lysis but no checkpoint contrast | Recognition/lysis constraint | Blockade interaction remains unvalidated |
| Relevant blockade evidence from another cancer or drug context | Explicit transfer/hypothesis stratum, with structural sensitivity | Never pool as prostate/selected-agent measured evidence |
| Only aggregate curves | Summary likelihood/interval constraints and source-level evaluation | No synthetic individual patients from means |
| Mean/SD but no joint covariance | Alternative joint distributions with stated assumptions | No uniquely calibrated multivariate patient population |
| Contradictory public results | Separate contexts and compare competing structures/parameter sets | Do not discard inconvenient studies or force compatibility |
| Only accessible figures | Controlled digitisation with uncertainty if lawful and readable | Do not digitise model curves as observations |
| No independently unused public validation set | Report development/source reproduction; search genuinely independent sources | Do not call training fit validation; core release needs its defined external exposure check |
| No usable public biological constraint | Acquisition/lead reassessment; C-INCOMPLETE | A PBPK-only source catalogue is not completion of this paper |

## Search stopping rules

Use six bounded lanes: PK, epigenetic PD/recovery, antibody pharmacology, prostate/immune function, upstream assets and independent evaluation. Each starts with primary precedents and two generations of directly relevant citation/related-object follow-up; retain a budget log (screened objects, time, exclusion reasons). Pagination must be exhausted for each executed API query or explicitly marked truncated. Stop a blocked object after its documented retry budget and one lawful anonymous mirror check; do not request accounts or confidential files.

Freeze the evidence coverage audit before model selection. Refresh targeted searches before analysis freeze and before manuscript submission, and when a source correction or retraction is found. Additions after evaluation exposure require a new model version and a new role audit.

## Strong versus weak fallback

A strong fallback is a public-data-constrained proof that timing is not identified, with quantitative consequences. A weak fallback is choosing broad ranges, generating many virtual trajectories and declaring all outcomes possible. The latter is not a completed scientific contribution. The standard for sufficient quantitative novelty is a scientific review gate, not a script returning zero errors.
