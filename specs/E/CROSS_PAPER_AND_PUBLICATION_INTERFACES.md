# Cross-paper and publication interfaces

A and A.1 can supply versioned programme/context evidence; B prostate regulatory evidence; C measured perturbation/drug evidence; D optional spatial/model outputs. None supplies numerical kinetic constants by virtue of being a thesis paper. E must run without D. A–C outputs that are unavailable have a public-evidence-only baseline route, specified before fitting and visibly distinguished from enriched versions.

E core owns exposure reconstruction, parameter/structure identifiability, evidence-constrained schedule contrasts and uncertainty. The biological paper owns its original experimental findings. E_LAST owns a new version's frozen prediction challenge and/or explicitly disclosed model update. Separate manuscript status for E_LAST is not promised; a transparent combined revision, addendum, follow-up paper or thesis module depends on distinct contribution.

| Object/claim | E core | Biological paper | E_LAST |
|---|---|---|---|
| Public PK/reconstruction | Primary analysis; cite originals | Context if needed | Reuse immutable released component |
| Public prostate experiments | Source-attributed curation/constraints | Literature context | Prior context; never new internal results |
| Original molecular/functional observations | Not a calibration dependency | Original experimental findings | Eligible model-development/evaluation input with disclosed reuse |
| Core schedule contrast | Conditional computational result | May motivate design, disclosed | Frozen hypothesis to test only after assay mapping and freeze |
| Original prospective outcome | Absent | Shared experiment if agreed | Prediction-versus-observation contribution; not a second independent experiment |
| D simulated outputs | Optional contextual sensitivity | Not measured validation | Optional model comparison only |

Every consumed handoff records source version, biological units, transformations, role exposure, permitted use and uncertainty. Same study/experiment/control appearing in more than one paper is linked, not duplicated. Core completion does not imply the entire thesis or A–D is complete; E_LAST additionally requires freezes of any optional interfaces it consumes.
