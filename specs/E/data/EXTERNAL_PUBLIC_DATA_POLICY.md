# Core external-public evidence policy

Required numerical scientific inputs are publicly accessible external evidence only. Prefer anonymous official APIs, published numerical tables, public source-data files, public regulatory reviews and openly released model equations/files. Public models containing unpublished or request-only inputs are not exact-reproduction dependencies. Public readability, machine accessibility and redistribution permission are separate properties.

Access states: open_numbers, open_table, open_figure, metadata_only, free_registration, restricted, unavailable, unknown. Free-registration/click-through resources require manual review and are optional until authorised; do not create accounts or accept agreements. Never use institutional, sponsor-confidential, controlled-access or author-request-only measurements as required inputs. A lawful figure digitisation is a derived extraction, not raw individual data.

For the first v2 core, the real-run allowlist requires `origin=public_external`, admissible object status, provenance, source-study identity, rights/use checks and a role assignment. A public number copied from an internal note must resolve to the original public object. A generated simulated curve cannot masquerade as public observations.

Original project experiments remain excluded from core model selection, calibration, weighting and public evaluation even when they arrive early. Once publicly published, they may enter a future disclosed version only after an independence/exposure audit; publication does not undo prior model-development exposure. They cannot be used to rescue a frozen v2 result secretly.

Private thesis governance documents may inform scope without becoming quantitative evidence. Release excludes originals, signatures, donor identifiers, credentials and restricted articles/files. Release retrieval recipes/locators and hashes; redistribute source objects only where permission is established.

The v2 schema also reserves `public_project_release` for genuinely public, permission-cleared project outputs admitted through an explicitly reviewed future-version amendment. This enum is not permission to use original unpublished experiments or to change the frozen first core retrospectively.
