## One authority, two scientific consumers

Paper A owns baseline biology, prediction, CYT-led endpoint sensitivity and qualified prostate transport. Paper A1 owns longitudinal estimands, timing/context interpretation and synthesis. This shared package owns source discovery, originating-study/publication identity, exact objects, private patients/treatment/specimens/assays/outcomes, overlap/exposure, pairing, branch admission and materialized matrices. No competing A or A1 identity registry is permitted.

## Preserved core and extensions

The original twelve normalized/receipt schemas, ontology and matrix documents, 14 DAV tickets, 15-row protocol crosswalk and 20-row historical implementation reconciliation remain included. The integration adds episode records/bindings, executable materialized-row schemas, exposure and branch-release contracts, a source-by-question candidate table and a machine-readable search plan. These are specification artifacts, not patient data or executed searches. JSON validity does not establish clinical linkage or a reviewer signature.

The episode extension is necessary because the inherited clinical-outcome/exposure records do not explicitly bind every record to a treatment episode. Existing records are preserved; the new shared bridge prevents outcome reuse across sequential treatments. See schema/version and migration details in the amendment.
