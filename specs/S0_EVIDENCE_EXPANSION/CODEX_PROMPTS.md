## Connector and MCP policy

GitHub read/write access was exercised in this planning session. Codex must discover its own actual tools, permissions and resource schemas; access in this chat does not prove access in another session. Use the provider's documented API when no relevant authenticated connector is available. Do not invent MCP method names or assume a generic fetch accepts every document URL.

Optional literature connectors found in the app directory were Consensus and Elicit; neither was installed/used for this kit. They are not prerequisites. Original publications, supplements and official source metadata remain the evidence authority, regardless of which search interface discovers them. Verify source identities instead of citing an agent's synthesized answer as experimental evidence.

Use least-privilege read access for source exploration. No credential copying, access-control bypass, paid-service activation, unattended subscriptions or patient-data transfer to new hosted tools. Respect rate limits, record failures, checkpoint retrieval and do not keep retrying blocked services indefinitely. Parallelize independent metadata searches only; shared source registries and final integration have one owner.
