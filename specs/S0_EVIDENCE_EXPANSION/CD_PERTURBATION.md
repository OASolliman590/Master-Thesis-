# C and D — Expanded sources without weakened evidence boundaries

**Scope proposal only.** Preserve `../C/DATA.md`, `../C/ANALYSIS.md` and all existing D checkpoint/benchmark contracts. This kit does not approve a new drug, dose, signature, class comparison or model.

## Paper C: expand independent measured evidence

The required source architecture remains TCGA/PRAD/LUAD and the B handoff; LINCS/CMap; CCLE/DepMap; PRISM/GDSC; DrugBank/ChEMBL; Perturb-CITE-seq/Frangieh/SCP1064; TISMO; proposed LJP4 IFNG reference; and GSE199800/GSE216053. A provider access issue remains a visible issue, not permission to drop its scientific role.

Search additional processed experiments by intervention identity, mechanism/class, prostate model/lineage, dose, time, assay and control. Prioritize experiments combining transcript restoration with measured methylation/chromatin or proteins and, where available, immune-cell co-culture or in-vivo immune endpoints. A gene knockout, a small-molecule inhibitor and a cytokine stimulation are different perturbations. Human cells, mice, organoids and patients are distinct biological contexts.

Each object needs original experiment, culture/animal/donor unit, biological versus technical replicates, control identities, perturbation/structure or guide, cell model, dose units, duration, measured feature space, QC, and overlap with discovery resources. Keep protein abundance, phosphorylation, viability and immune killing as separate outcomes. Concentration matching alone does not remove project/batch confounding.

For LINCS, distinguish directly measured landmarks and inferred features. A response inferred from the same perturbation data cannot serve as an independent measured validation. Multiple releases of the same profiles or multiple wells from one culture are not independent experiments.

### Multi-omics value test

Ask what the methylation/chromatin/protein layer changes relative to an expression-only prioritization, using a prespecified evaluation on independent measurements. Use a common evaluated drug/model set and report coverage. Do not select the independent validation dataset after seeing which drugs rank well, and do not turn a generic cytotoxic signature into immune restoration.

The nominated restoration direction must be justified separately from A's classifier sign. A positive predictor coefficient is not an instruction to upregulate that gene in a cancer cell. Preserve conflicting genetic, composition, exposure and pharmacological evidence in the B-to-C handoff.

This expansion may suggest changes to a future wet-lab design, but it does not silently change the submitted protocol or the internal experimental plan. Drug approval for one indication does not establish approval or efficacy for prostate immune priming; exact regulatory and exposure claims require primary verification.

## Paper D: expand only to eligible independent benchmarks

Search processed prostate perturbation objects with a checkpoint-compatible feature representation, supported chemical identity, matched controls, biological replication and treatment exposure. Verify training/pretraining overlap at original experiment and dataset level. A different repository filename or processed release does not make a previously trained-on experiment unseen.

Record supported-drug context transfer separately from globally unseen-drug prediction. No unknown-treatment fallback to control can pass as a supported prediction. Preserve the existing same-drug cross-context baseline and permit additional simple baselines only under a predeclared fair information set.

Report a coverage matrix rather than an assumed Cartesian product: `catalogued`, `measured`, `QC_pass`, `usable`, `not_screened`, `access_blocked`, `unknown`. D remains conditional when native representation or independent ground truth cannot be established. An inference command succeeding is not scientific benchmarking.
