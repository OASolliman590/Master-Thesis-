## B-F1 exact reviewable ticket: four file formats only

**Disposition: proposed for independent review; not ready/released.** It may be released by the orchestrator after all four specification reviews even while B's biological feature/model gates remain blocked. Its acceptance is file-format correctness only. No code is created by this ticket.

**Ownership:** proposed isolated paths `tools/b_formats/` for the import-inspection module and `tests/b_formats/` for tests and tiny synthetic fixtures; one small provenance/check-result artifact under `docs/validation/B_formats/`. The implementer may not edit analysis specs, cohort files, other papers, shared environments, root configuration, prior raw data or source manifests. These path reservations require orchestrator confirmation when dispatching. The implementer returns a diff and actual test logs; the orchestrator owns review/commit/publication.

**Runtime:** Python 3.11 standard library only (the observed AIU Python 3.11.16 is the candidate executable). No pip installation or global environment change; no pandas/numpy/sklearn, network call, cohort download or biological processing. Read-only local fixture access and a bounded output directory. Standard-library parsing/typing, missing-token classification and shape/identifier counts are within scope; normalisation, imputation, probe/gene selection, score construction and patient association are not.

**Implemented WIP interface:** `python -m tools.b_formats inspect --format FORMAT --input PATH --source-sha256 HEX --completeness full|bounded-prefix --output SUMMARY.json`. The local interface was exercised; AIU verification remains pending. Allowed FORMAT values are `tcga-star-expression`, `tcga-methylation-beta`, `cpc-expression`, `cpc-methylation`. Tests invoke an explicit Python executable and argument array via subprocess without a shell. Exit0 means a valid new inspection;2 means invalid arguments or an existing output;3 means checksum/schema failure;4 means I/O failure. Complete JSON publication refuses competing output paths. Diagnostics contain paths/reasons but no assay values or credentials. An expected bounded prefix ends after the last complete row and explicitly reports `completeness=bounded-prefix`. Hash mismatch or a malformed record fails; syntax alone cannot prove full-source completeness. See the actual guide and receipts under docs/validation/B_formats/.

**Bounded first implementation:** accept the four listed uncompressed UTF-8 TSV fixtures only. Gzip acquisition/decompression is outside B-F1 and compressed input must be rejected explicitly. A plain TSV ending at a complete record cannot reveal that later records were removed without independent expected size/hash/row-count evidence; the tool certifies conformance to the supplied hashed artifact and declared completeness, not source completeness from syntax alone. A missing final newline alone is not proof of truncation. Malformed/incomplete records must fail even in declared prefix mode; prefixes have already been cut to complete records by the acquisition audit.

The expected SHA256 is checked against the **actual local input bytes before parsing**, not copied from an unrelated full object. Compressed prefix and decompressed prefix have distinct digests. SourceManifest entries or the existing fetch log supply known compressed/full hashes; any selected derived TSV uses a separately recorded local SHA and parent provenance. Do not use the new full GSE107299 SHA as the checksum of its older retained prefix. Retain the full-expression audit as coverage metadata; do not redownload its unretained matrix for B-F1.

**Copying/output limits:** read existing fixtures in place on the authorised host or transfer only these explicitly enumerated fixtures through the orchestrator's approved route. No recursive dataset copy, full cohort matrix, new download or raw data added to Git/Notion. The two full single-specimen examples total about 17.4 MB; prefixes retain their existing bounded sizes. Commit only code, tiny synthetic fixtures, permitted schema/count summaries and a manifest with path/bytes/SHA256/provenance/completeness. Confirm source-specific redistribution before copying any real row to a repository fixture; otherwise all real data stay in approved storage. Summary output contains no per-patient expression/methylation matrix.

**Acceptance:** independently verify observed hashes/counts above; each of the four CLI modes succeeds on its actual allowed fixture and yields its declared schema/count summary. Meaningful negative tests cover wrong SHA, unexpected row width, a false missing-header repair, a duplicate identifier, invalid beta token, intentional prefix versus undeclared truncation, and conflating detection-P with beta fields. Two subprocess runs produce the same scientific summary fields (timestamps may differ); malformed inputs produce no completed success artifact. The test log records executable version, input hashes, actual arguments/exit statuses and resulting summary hashes. Synthetic fixtures exercise parser failure semantics; they do not establish biological correctness. Report AIU tests as pending if VPN fails; a local pass is labelled local. No B score, model or scientific figure may be generated to demonstrate this ticket.

## High-value test requirements

1. **Real table schemas:** verify first TCGA methylation probe retained, NA count/row count match the inspected object, beta and detection-P separation, 788/789 GEO header repair only for the documented missing-label pattern, all seven expression annotation fields excluded from patient values, and STAR N_ rows removed. A wrong shape or unexpected duplicate ID must fail, not be auto-healed.
2. **Patient independence:** duplicate a reanalysis record and show independent n is unchanged; add unresolved second focus and require unresolved status rather than an averaged patient; candidate F1 prefix bridge alone cannot pass same-focus linkage. Assert no patient across TCGA folds and no TCGA identifiers imported through the pooled CPC2017 portal.
3. **Score invariants:** ranks/score unchanged by a strictly increasing transform applied to every gene within one sample; another patient's values cannot affect that sample's score; tied genes receive midranks; gene-order permutation preserves score; missing required genes/universe produce explicit ineligibility. Adding a gene to U changes its hash and is forbidden under a locked model.
4. **Promoter mapping/QC:** synthetic semicolon-aligned annotations map each gene to the correct region; body-only probes cannot become promoter features. NA is missing, beta zero is measured. Training-selected Q and statistics cannot change when external values are altered. Coverage boundary cases around the proposed 80%/95% rules follow the final frozen definitions.
5. **Leakage sentinels:** replace external Y by random/reversed values and assert identical fitted models, transforms and C query hashes. Alter an inner validation fold's values and show its training preprocessing is unchanged. Spy/trace fitting calls to verify they never receive external IDs.
6. **Metric oracle:** manually constructed Y/f0/f1 cases reproduce Delta_R2=(SSE0-SSE1)/SST, identity models give zero, exact extended predictions improve error, worse predictions can yield negative R2, and constant Y yields undefined. Both models must use the same patient set; correlation cannot substitute for R2.
7. **Bootstrap unit and reproducibility:** resample whole paired patient rows; never split f0/f1 or sample replicate records. Fixed seed gives repeatable intervals within the pinned numerical environment. Record undefined resample counts; test n<2 and duplicate-patient rejection.
8. **Scientific boundary exports:** positive promoter associations survive export; domain proxies and missing CNA flags remain visible; a C-query file containing external-selected provenance is rejected. Failed/null primary metrics cannot be overwritten by a secondary analysis path.

Use small controlled fixtures for invariants and the already inspected permitted real formats for integration evidence. Synthetic success validates computation, not biological transport, coverage, precision or publication novelty. One full approved AIU run with independent review remains required; repeat broad tests only for changed dependencies or unresolved failures.
