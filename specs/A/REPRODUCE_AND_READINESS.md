# Reproduction and readiness — independent states

## Current state

The integrated architectural Spec Kit is deliverable for review. Source search/population construction, patient admission, numerical statistical freeze, analysis software validation, AIU environment validation and real scientific results are NOT established by document completion. Inherited DAV test reports are historical package evidence unless explicitly rerun. The new package verification report records only checks actually performed in this revision.

## Gate matrix

G-SPEC: populated contracts, resolvable schemas, decision/migration consistency, tests and bounded tickets. G-SOFTWARE: implemented behavior with fresh focused/relevant full tests and pinned environment. G-DATA(branch): source identity/bytes/terms, endpoint/episode, assay/coverage, overlap/exposure and matrix/admission receipts. G-STAT(branch): roster, numerical settings, covariates, contrast, multiplicity, precision and applicable reviewer freeze. G-HANDOFF: development-only B/C artifacts locked. G-TEST: one qualified A-P2 evaluation with model/splits/weights fixed. G-PUBLICATION: distinct question/evidence/precision/overlap assessment, independent of significance.

A-P2 needs G-SOFTWARE, its G-DATA/G-STAT, model freeze and protected-set evaluator release. A-BIO does not need A-P2 success or even a final-test dataset, but still excludes reserved families. A-P1 CYT does not need a trained model. A1 pairing, estimation, synthesis, moderators and publication have separate gates. Optional methylation/spatial/comparator failure cannot deadlock an unrelated RNA branch.

## Reproduction bundle

Pin Git commit, package/schema versions, Python/R lock or container digest, source-object SHA-256s and terms, private normalized-store and patient-membership hashes, admission/build/split/exposure receipts, configurations, RNG/threads, exact commands, complete tested outputs and permitted aggregate figures. Fresh build starts with empty outputs, uses only declared verified inputs and reproduces hashes or declared numeric tolerances. Resume checks all input/code/config/schema/environment identities. Unavailable raw matrix beneath a historical report is a blocked reproduction, not a successful rerun.

## Reportable states

Use SPECIFICATION_VERIFIED, SYNTHETIC_SOFTWARE_TESTED, REAL_SOURCE_FORMAT_TRACED, BRANCH_DATA_RELEASED, STATISTICALLY_FROZEN, SCIENTIFICALLY_EXECUTED and INDEPENDENTLY_REVIEWED only for the corresponding evidence. UNKNOWN/NOT_RUN/BLOCKED are first-class states. The phrase 'implementation-ready' is scoped: the first recovery/intake packet may be ready to implement while statistical/clinical execution remains blocked.

No new scientific CLI is claimed to exist merely because SOFTWARE_ARCHITECTURE lists its proposed invocation. No final test, trained model, signature, patient N or publication is delivered by this package. Stop the current implementation packet before any expression–response calculation.
