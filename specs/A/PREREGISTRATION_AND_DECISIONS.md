# Prespecification, decisions and release chronology

Architecture is selected by the October handoff; the scientific analyses are planned for prespecification/preregistration, not already registered. A dated Git file records its actual date and prior exposure; it cannot create retroactive prospective registration. Any external registration requires the true platform/ID/date and a separately authorized submission.

## Freeze sequence

F0: integrated schema/interface and privacy contracts. F1: declared source universe, patient/episode/endpoint reconstruction, overlap/exposure and reserved family boundary. F2: branch admission, matrix/feature coverage and split receipts. F3: statistical configuration including assay effect scale, covariates, model settings, precision assessment, multiplicity and test weights. F4: development-derived A-BIO/context handoff. F5: learned predictor and exact scoring bundle. F6: one final-test evaluation release with all required sources. A1 has independent F2/F3 releases and never bypasses the global protected set. Branches do not wait for irrelevant optional modalities or publication promotion.

## Decision statuses

SELECTED_ARCHITECTURE is not NUMERICALLY_FROZEN, SOURCE_ADMITTED, SOFTWARE_VALIDATED or SCIENTIFICALLY_RUN. A null is an observed result only after a valid run; a blocked branch is not a null. All fields in NUMERICAL_FREEZE_REGISTER.tsv carry current value/status, owner, needed evidence and blocked stage. null/UNKNOWN means execution must fail closed at that gate, not insert defaults.

## Amendment rules

Changes to A-P2 estimand, weighting principle, independent-test standard, raw-data processing or treatment/cancer claim scope need explicit user review. Numerical settings may be proposed from admitted structure and molecular–outcome-association-free planning; the statistical reviewer records the actual freeze. After any outcome/performance inspection, disclose the exposure and label subsequent changes exploratory or newly validated rather than pretending they were prospective. A failed required source cannot be silently removed. Old documents and receipts are immutable historical records.

## Protocol communication

PROTOCOL_CROSSWALK.md prepares the distinction between original commitments and revised methods. Supervisor contact, institutional paperwork and acceptance remain outside this task. A1's thesis-default publication placement does not by itself establish an institutional amendment requirement. No reviewer's scientific signature is manufactured in an example receipt.
