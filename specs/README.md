## Decisions needed before scientific production

The central thesis question remains prostate epigenetic immune regulation with its registered wet-lab component. Four computational manuscripts are a programme ambition, not a promise of four publishable findings or degree approval. The design must fit approximately 600 researcher-hours over four months; acceptance timing and institutional publication requirements are not established here.

The current primary proposals make the original ideas statistically explicit but may shift emphasis, especially A toward endpoint sensitivity and B toward predictive molecular transport. Independent review must assess whether those choices best serve the thesis. Preserve alternative full-scope modules and the original history. A material emphasis change is not accepted merely because it appears in a draft.

Default implementation sequence remains minimal shared interfaces, B, C, A, then D if its feasibility gates pass. Only one paper's production implementation is active at a time. All four design packages require independent review first. Endpoint-independent import/validation tickets can be evaluated separately from blocked scientific models; such a ticket must have an exact contract, review receipt and explicit scope. Passing parsers is not implementing or validating the paper.

Each paper has four planned figures, coverage tables, a primary estimand, validation boundaries, preregistration/decision ledger, software contracts and bounded tickets. Conditional sections openly retain missing evidence rather than replacing it with guessed samples, thresholds or model capabilities. No `ready-for-agent` label belongs on a blocked parent specification.
