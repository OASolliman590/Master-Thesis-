## Access, identifiers and permissions

Record originating study and source release separately; keep original sample/compound names beside canonical IDs. Reject ambiguous mappings instead of fuzzy merging. For human–mouse analyses use a pinned orthologue source with one-to-one primary mapping and separately report absent/ambiguous mappings. Do not silently expand one human gene into multiple mouse genes.

LINCS public redistribution policy differs from historical hosted-platform terms. DepMap-generated data are generally CC-BY4.0, with external-source exceptions; PRISM19Q4v4 is CC-BY4.0; ChEMBL database CC-BY-SA3.0; DrugBank access/licensing must be checked for the actual licensed input. GDSC exact release terms and selected immune-context object terms remain unresolved. Store source-specific permissions in the manifest; do not apply the code license to all source data. No credentials, signed session URLs or restricted source files enter Git/Notion/delegation briefs.

## Required materialised coverage artifact

`coverage.tsv` must have one row per source × molecule/target × model × exposure/condition × assay, with distinct states `catalogued`, `measured`, `qc_pass`, `usable`, `not_screened`, `access_blocked`, `unknown`; independent N and its unit; source hash; reason. No Cartesian product of dictionaries may be labelled measured. A zero count, failed request and measured null result have different meanings.
