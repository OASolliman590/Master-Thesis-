# Gene set attribution

`hallmark_2026.1.Hs.gmt` and `reactome_2026.1.Hs.gmt` are reformatted exports of Molecular Signatures Database (MSigDB) release 2026.1.Hs, obtained through the R package `msigdbr` 26.1.1. The change made here is the file format: gene symbols sorted within each set and written as GMT.

MSigDB content is licensed under CC BY 4.0, with extra terms for some gene sets that are not used here: https://www.gsea-msigdb.org/gsea/msigdb_license_terms.jsp. Reactome data are under CC0: https://reactome.org/license.
