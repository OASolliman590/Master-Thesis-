# Modules enabled by actual data

The extension is not an all-or-nothing 'inject data' step. Enable only the modules identified by the reviewed capability snapshot.

| Module | Minimum informative capability | Output |
|---|---|---|
| Descriptive transfer | Valid assay-scale observations/identity/events | Context agreement/disagreement, no kinetic inference |
| Tumour net-growth/toxicity | Target-specific counts or valid tumour-only viability with exposure/time controls | Identifiable growth/toxicity combinations |
| Target/phenotype static PD | Dose-response or endpoint contrasts plus relevant proximal/protein measurement | Assay-scale dose-effect constraint |
| Induction dynamics | Adequate public-foundation mapping plus tumour time course | Identifiable induction/delay subset |
| Recovery | Treatment and withdrawal events, tumour trajectory extending after withdrawal, carryover assessment | Supported persistence/recovery on the measured scale |
| Immune survival | Valid immune viability/count/time data | Immune loss/recovery within measured context |
| Immune competence | Viability plus function over time | Separate functional impairment/recovery |
| General functional QSP | Target-specific killing with tumour-only and immune controls | Killing/recognition parameters or identifiable combinations |
| Checkpoint-functional QSP | General functional requirements plus qualified selected axis/antibody contrast | Functional checkpoint effect, not affinity copied as efficacy |
| Schedule evaluation | Qualified functional controls, recorded comparable schedule arms and fixed outcome | New-version reconstruction or independent prediction evaluation according to role |
| Experimental population | Repeated independent units and defensible variance/correlation information | Context-defined experimental variability; no patient-population relabelling |
| Exposure bridge | Validated analytical concentration-time observations in relevant compartments | Only the observed bridge terms |

Timepoint count alone does not establish identifiability. Use sensitivity/profile/multistart or posterior diagnostics, measurement precision and model comparison. A single biological unit can support limited within-system description; it cannot identify a donor distribution. If statistical precision is insufficient, report it rather than invent additional biological N.

No default dose, timing grid or sample size is imposed. Before any new experiment, use pilot variability (development data) and prospective precision/model-discrimination calculations to choose the design. Design adaptation cannot turn pilot data into prospective validation. Inherited assay suggestions remain proposals until locally qualified and approved.
