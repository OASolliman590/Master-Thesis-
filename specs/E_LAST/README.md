# Optional experiment-informed upgrade to Paper E

The extension asks whether the finished public-evidence foundation transfers to the actual local system, which parameters new measurements can identify, and whether frozen predictions agree with independent observations. It may add calibration, retrospective evaluation, prospective validation or only a narrowly scoped descriptive bridge. None is labelled another kind of evidence.

Input: an immutable E-core release plus admitted original observations. Output: an extension receipt, a new model/version when updating is justified, before/after predictions and uncertainty, and an explicit list of claims gained/not gained. No inherited core outputs are overwritten.

This package can be read independently. It consumes the released foundation through `FOUNDATION_INTERFACE.md`, not through undocumented chat context or hard-coded core internals. The future command names are specification targets, not implemented production tools.

Optional source: A–C frozen contextual handoffs and D prediction products only if an approved branch needs them; D is never mandatory. New animal or human interventional work is not authorised. Human donor sampling or tissue use requires applicable institutional permission even for self-donation.
