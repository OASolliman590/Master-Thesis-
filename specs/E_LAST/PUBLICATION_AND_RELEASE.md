# Publication and release of the optional extension

The public core keeps its original title/claims/data freeze and does not wait for these experiments. The extension may become a disclosed version upgrade, a distinct follow-up, a biological-paper modelling module or a thesis-only validation chapter. Its existence does not guarantee another manuscript.

For every shared experiment specify which paper presents the experimental mechanism, which presents the frozen prediction test, which figure/data object is reused and why the contribution is distinct. One dataset/experiment cannot count twice as independent biological validation. Reproducing a figure without a distinct disclosed analysis is not a new finding.

Release code, environment locks, public retrieval manifests, model/version identities, data-role decisions, permitted deidentified derived observations and figure receipts. Retain institutional originals, consent/approval records, donor keys and restricted data outside the public bundle. Public model parameters derived from sensitive data may themselves need release review.

Outputs include enabled/disabled capability matrix, admitted/excluded observation manifest, foundation/extension difference report, pre-update prediction evaluation, post-update diagnostics if performed, claims gained/not gained, unresolved items and a negative-result disposition. Permission withdrawal follows institutional policy and may require withdrawing affected releases; do not silently regenerate observations.
