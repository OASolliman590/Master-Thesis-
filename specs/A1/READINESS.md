# A1 readiness and release states

A1 is active and fully specified. It is not already paired, fitted, externally preregistered or publication-ready. Use branch/window-specific states rather than one global green flag.

| Gate | Required evidence | Failure blocks |
|---|---|---|
| L0 Specification | Populated contracts, shared-schema bindings, contrast registry, tests and review | Implementation handoff if inconsistent |
| L1 Pairing | Source-supported patient/episode/time/assay joins and deterministic pair receipt | The affected paired contrast |
| L2 Estimation | Both required response groups, full-rank model, compatible scale, frozen window/covariates, fresh software/environment tests | That interaction/model only; valid group change may remain |
| L3 Synthesis | At least two independent admitted families with compatible estimands and usable uncertainty/covariance | Cross-study claim, not the valid within-study effect |
| L4 Moderator | Context design rank, independent information, precision and predeclared comparison | That cancer/class/regimen/time moderator |
| L5 Corroboration | Actual modality pairing/localization, reference method, nested unit and coverage | Optional corroboration only |
| L6 Publication | Distinct question, sufficient independent evidence/precision, novelty and nonduplicative figures | Separate manuscript, not thesis analysis |

All gates additionally obey the shared protected-set/exposure policy. An A-P2 test reservation cannot be evaded by analysing the same patients longitudinally. Missing final-test data for A-P2 does not block an otherwise released A1 population. A clinical NMA is not a prerequisite at any A1 gate.

Current actual patient N, paired N, admitted study count, usable windows and moderator rank remain UNKNOWN. Candidate source totals from old reports are not releases. Numeric windows, covariance model, multiplicity, bootstrap settings and precision thresholds remain in the shared/A numerical freeze register until source-dependent review.

Reproduction requires immutable source objects, normalized registry snapshot, pair/endpoint/build/admission/split hashes, model/config/environment versions and exact commands. Resume invalidates outputs after any timing, endpoint, source, assay or pairing change. A new pairing version cannot silently reuse an old effect table. Report all missing-data/selection assumptions and unsupported claims; a blocked result is not a null result.

A1-to-A/B/C products contain observational effect and timing support only. A1-to-D/E products are source-conditioned temporal observations, not automatically causal response functions or PK/PD constants. Preserve thesis inclusion even when separate publication remains undecided.
