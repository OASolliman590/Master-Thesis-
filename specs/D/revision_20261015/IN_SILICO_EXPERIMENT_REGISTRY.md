# In-silico experiment registry

Each hypothesis record includes input context, intervention, comparator, model version, output, independent wet-lab readout, success criterion, falsifying result, uncertainty, and claim ceiling.

| ID | Hypothesis | Initial D2-PAIR status |
|---|---|---|
| H1 | priming increases tumour immunogenicity programme | molecular/protein readouts required |
| H2 | priming improves or impairs immune-cell state | immune exposure required; not assumed |
| H3 | priming increases recruitment | unsupported in D2-PAIR unless recruitment is measured/modelled |
| H4 | priming increases antigen-presentation eligibility | surface/protein plus function required |
| H5 | myeloid remodelling | unsupported until myeloid compartment exists |
| H6 | priming-before-ICI outperforms concurrent/reverse | hypothesis generating until measured |
| H7 | effect differs by qualified prostate context | requires multiple qualified contexts |
| H8 | baseline/induced resistance prevents benefit | resistance readout and falsification required |

“The simulation changed” is never a success criterion.
