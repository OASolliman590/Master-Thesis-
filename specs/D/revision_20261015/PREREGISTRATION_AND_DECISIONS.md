# Preregistration and decisions

## Prior exposure

The team has inspected the historical D specification, STATE/Tahoe metadata, Lin paper/release information, and proposed prostate/wet-lab sources. Git history is not external preregistration.

## D1 freeze requirements

Actual test accession/independent units, complete feature/transform contract, exact checkpoint hash, perturbation identities, training lineage, fixed baseline rows, split, precision/interval decision, secondary metrics, and source terms.

## D2 freeze requirements

Qualified assay, calibration/test experiment identities, geometry, cell systems, parameters/priors, observation model, nonspatial/rule baselines, primary endpoint/timepoint, scenarios, success/falsification rules, and model-update prohibition until evaluation is archived.

## Amendment rule

Each amendment records date, reason, prior outcome exposure, old/new decision, affected tickets/figures, and whether a new independent test is required. A D2 primary can be selected only before confirmatory outcome inspection.
