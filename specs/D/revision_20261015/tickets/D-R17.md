# D-R17 — Bounded scenario registry

## Deliverable

Freeze a small single-agent/concurrent/sequence set with assumptions and outputs.

## Acceptance

No Cartesian expansion; no synergy claim without measured null design.

## Boundary

Hypothesis generation only until V7/V8.

## Required workflow

1. Read controlling spec and dependencies.
2. Write the failing behavioural/adversarial test where code is involved.
3. Run it and record the expected failure.
4. Implement the smallest compliant change.
5. Run scoped tests and applicable project regression tests.
6. Record actual commands, versions, outputs, skipped/deferred checks, hashes, and remaining gates.
7. Submit for integrator review; do not self-merge.
