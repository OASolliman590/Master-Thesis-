# Scientific aim and permitted claims

## Overall aim

Develop an auditable staged system that evaluates cell-intrinsic perturbation predictions and, separately, predicts experimentally observable tumour–immune outcomes under epigenetic priming and checkpoint blockade.

## Primary questions

### D1

Does a frozen perturbation model reduce prediction error relative to the exact fixed same-supported-drug–dose–duration response baseline in independently measured human prostate conditions?

### D2-PAIR

Does a measured-driver spatial tumour–T-cell model improve prediction of held-out tumour burden/killing over a nonspatial population model and a minimal rule-only spatial model?

## Secondary questions

- Does learned molecular coupling add held-out value beyond measured-driver/rule models?
- Does the preferred sequence differ across qualified prostate archetypes?
- Which discrepancies reveal missing biology rather than parameter tuning opportunities?

## Claim ladder

| Highest passed evidence | Maximum permitted claim |
|---|---|
| V0 software reproduction | software can reproduce an upstream path |
| V1 molecular benchmark | accuracy for the declared molecular benchmark |
| V3 observer validation | observer recovers declared state labels/probabilities |
| V4 functional/composition validation | model predicts the declared multicellular endpoint |
| V5 spatial validation | model predicts declared spatial metrics |
| V6 longitudinal validation | model predicts held-out observed transitions |
| V7 measured combination validation | combination outcome under the tested null/design |
| V8 prospective validation | preregistered prediction supported or contradicted in new experiments |

No level supports individualized clinical recommendations under the current design.
